# Fontes dos PDFs

DejaVu Sans Regular e Bold, versão 2.37. Usadas somente pelo renderizador de PDF no servidor, incorporadas por subconjunto. Preservam acentos e símbolos técnicos como `μ`, `≤`, `≥` e `⌀`.

Origem: pacote oficial `dejavu-fonts-ttf-2.37.zip`, obtido em https://github.com/dejavu-fonts/dejavu-fonts/releases/download/version_2_37/dejavu-fonts-ttf-2.37.zip.
