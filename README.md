# Vê AI

Agente que investiga imóveis num portal autorizado usando um navegador,
consulta dados geográficos reais, compara as opções segundo as prioridades do
usuário e, com aprovação, solicita uma visita, verificando o registro de forma
independente.

Projeto da equipe Capengas para o Converge Challenge 2026 (Recife, 7–8/11/2026).

**Estado:** planejamento. O desenvolvimento começa em 07/11 às 10h; ainda não
há código.
